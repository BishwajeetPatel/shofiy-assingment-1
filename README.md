# shofiy-assingment-1
This project is a redesigned product listing page for an e-commerce website, built with a focus on modern UI/UX, responsiveness, and interactivity. The page is crafted to offer a seamless and engaging shopping experience on both mobile and desktop devices.

✨ Features 🔍 Product Section Main Product Display with thumbnail preview and active state.

Interactive Color & Size Selection with visual feedback.

Quantity Selector with validation (min 1, max 10).

Add to Cart Animation to enhance user engagement.

Wishlist Button Toggle with icon and text change.

Size Chart Modal:

Positioned right below the product name.

On click, opens a modal popup with a reference image (can be replaced).

Modal supports click outside and Escape key to close.

🖼️ Related Products Section Horizontally scrollable carousel of related product cards.

Swipe gestures on mobile and mouse wheel scroll on desktop.

Smooth scroll behavior.

Includes up to 8 sample product images.

📬 Newsletter Signup Simple email subscription form with user feedback.

⚙️ Additional Functionality Mobile navigation toggle for responsive menu.

Lazy-loading for images using IntersectionObserver to improve performance.

Fully responsive layout adapting to all screen sizes.

📱 Responsiveness The entire layout is built with mobile-first design principles and adapts beautifully to various screen sizes using:

Flexbox and CSS Grid

Media queries

Mobile gesture handling for sliders

🛠️ Technologies Used HTML5 – Semantic layout and structure.

CSS3 – Styling, transitions, modal, and responsive design.

JavaScript (Vanilla) – DOM manipulation, event handling, and UI logic.
